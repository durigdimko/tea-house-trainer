# Тренер «Чайный домик Китти»

Подсказывает лучший ход в игре «Чайный домик Китти» (клон Triple Town): смотрит на экран, сам видит ходы, считает.
Один файл index.html, открывается в Chrome/Edge. Память — в браузере (localStorage) и в tea-house-memory.json.

## Как пользоваться
1. «📷 Начать захват» → выбрать окно игры → «Выделить поле» (обвести 6×6 по краям клеток) — один раз.
2. «Рамка и чувствительность» → «🎯 Заново выделить окошко «в руке»» → обвести квадратик слева внизу в игре — один раз.
3. «📥 С картинки» → просто играть. Зелёная 1 — лучший ход.
4. Новая иконка в окошке — один раз нажать её клавишу 1–9. Ошибка мигающей — правый клик → «✨ Здесь мигает».
5. После партии — «💾 Сохранить память в файл».

## Правила (как в коде)
- Поле 6×6, клетка 0 — поднос (хранит 1 предмет, обмен тапом).
- Десерты: 🍪→🍞→🍮→🍫→🧁→🍰→🎂→🎂✨ (3+ одинаковых рядом сливаются в клетке хода).
- Чай: 🍵→🍨→🏡. 🍵 получается, когда белого кота 🐱 заперли (вокруг группы нет пустых клеток).
- 🐱 белый кот ходит на соседнюю пустую. 😼 рыжий прыгает в любую пустую.
- 🍴 вилка УДАЛЯЕТ предмет/кота (клетка пустая). 📺 духовка — джокер (становится лучшим для слияния, иначе 🫖 мусор).
- Очки за слияние (÷10): 🍞4 🍮20 🍫50 🧁150 🍰500 🎂1500 🎂✨5000 🍨100 🏡500 (🍫, 🎂, 🎂✨ не уточнены).

## Как устроено
- Распознавание поля: образцы клеток (векторы 471 значение), ближайший образец.
- Что в руке: квадратик игры слева внизу, сравнение с его же снимками (tth_panel, tth_panel2).
- Где мигает: белая подложка под мигающей (сравнение с такими же иконками на поле), иначе — по правилам (куда ушли коты).
- Ход: каждый вариант доигрывается тысячи раз на 10–14 ходов вперёд на всех ядрах (Monte Carlo).
- Поднос: ценность 🍴 растёт с числом рыжих, 📺 — с теснотой поля.
- Веса оценки поля (WT) подбираются самоигрой: «⚙️ Расчёт и очки» → «🧪 Подобрать».

## Структура файла
Основной код + один блок «ДОРАБОТКИ» + мелкие блоки в конце: вилка удаляет кота; ценность чайной цепочки (W 12:20 13:40, MAT 12:30 13:150 14:800).

## Что дальше

- Держать 🍴 до момента, когда удар по рыжему выгоднее всего.
- Уточнить очки за 🍫, 🎂, 🎂✨.
