# Тренер «Чайный домик Китти»

Подсказывает лучший ход в мини-игре «Чайный домик Китти» (Tree of Savior: NEO, клон Triple Town).
Тренер смотрит на окно игры через захват экрана, распознаёт поле 6×6 и показывает ход. Сам он в игре ничего не нажимает.

**Открыть:** https://durigdimko.github.io/tea-house-trainer/
Работает в Chrome или Edge на компьютере: телефонные браузеры не дают захватывать экран.

## Как пользоваться

1. «📷 Начать захват» → выбрать окно игры.
2. Один раз: «Выделить поле» (обвести сетку 6×6 по краям клеток) и в «Рамка и чувствительность» → «🎯 Заново выделить окошко «в руке»» (квадратик слева внизу в игре).
3. «📥 С картинки» → играть. Зелёная **1** — лучший ход, при наведении мыши видно, что будет.
4. Над советом пишется статус сверки поля:
   - ⏳ сверяю поле — подождать долю секунды;
   - ✔ поле сверено / ✔ поправил поле — можно ходить;
   - ❔ не смог сверить — если поле не совпадает с игрой, нажать «📥 С картинки».
5. Тренер ошибся с фигурой — правый клик по клетке → «Лежит на поле» или «✨ Здесь мигает».
6. Неверно понял, что в руке, — кликни нужную иконку в палитре. Твой выбор держится до хода, окошко «в руке» его не перебивает.

## Как он считает ход

- **Правила игры** встроены в тренер (проверены по записям партий):
  - слияние 3+ одинаковых, очки не зависят от количества фигур; очки дают и сами постановки (🍪 5, 🍞 40, 🍮 100, 🍫 500);
  - 🐱 белый кот ходит на соседнюю пустую клетку; группа белых без пустых соседей становится 🍵, но не тогда, когда рядом рыжий и на поле есть пустые клетки;
  - 😼 рыжий прыгает в любую пустую клетку, запереть его нельзя; в 🍵 он превращается, только если после хода на поле не осталось пустых клеток;
  - 🍴 удаляет фигуру или кота, 📺 — джокер.
- **Оценка поля выучена самоигрой**: 168 000 партий по правилам выше, обучение TD на таблицах по окнам поля 2×2, 1×3 и 2×3, как у ботов для 2048. Ручных весов больше нет.
- **Расчёт** — ожидание на 2 хода вперёд по частотам выпадения фигур. Совет считается за сотые доли секунды.

В симуляции (средний счёт без магазина):

| Версия | Средний счёт |
|---|---|
| v4, ручная оценка | ~40 700 |
| v5, + доигрывание | ~56 000 |
| v6.3, выученная оценка | ~85 000 |
| v6.6, выученная оценка по исправленным правилам | ~280 000 |

v6.3 считалась по старым правилам, v6.6 — по исправленным, поэтому эти две цифры напрямую не сравнить. На одних и тех же партиях по исправленным правилам: v6.4 — ~93 000, v6.6 — ~280 000. Это расчёт на 1 ход; тренер считает на 2, так что в симуляции выходит больше. В живой игре мешают ошибки распознавания.

## Запись партии

«⏺ Начать запись» → играть → «💾 Скачать запись». Файл (кадры поля + как тренер понял поле + советы) нужен для разбора ошибок распознавания. Запись хранится только в открытой вкладке, пока её не скачали.

## Файлы

- `index.html` — весь тренер одним файлом, выученная оценка встроена внутрь.
- `tea-house-memory.json` — стартовая память распознавания (картинки иконок). Подгружается, если в браузере своей памяти ещё нет.
